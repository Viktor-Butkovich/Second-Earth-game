\section*{Spaceport Notes}
\begin{itemize}
    \item Compared to other colony infra, a spaceport is of nontrivial but only moderate complexity.
    \item It is analogous to a small airport, with components being:
    \begin{enumerate}
        \item Landing/launch pad
        \item Control and navigation facilities
        \item Refueling equipment
        \item Loading/unloading facilities
        \item Blast shielding
    \end{enumerate}
    \item Constraints:
    \begin{enumerate}
        \item Cannot physically lie within a dome
    \end{enumerate}
    \item Materials per attempt: 1.46 total
    \begin{itemize}
        \item Base metals: 0.2 T2
        \begin{itemize}
            \item Makes up about 1/6 of total materials - steel/aluminum (T2) for structural frames, refueling
                equipment, etc.
        \end{itemize}
        \item Building materials: 1.0 T1, 0.2 T2
        \begin{itemize}
            \item Suppose 80\% of materials are simple (T1) and can be based on relatively unprocessed regolith
            \item Suppose 20\% of materials are more specialized (T2) composites, ceramics, etc.
        \end{itemize}
        \item Advanced metals: 0.05 T1, 0.01 T2
        \begin{itemize}
            \item Relatively few, but sensors, navigation equipment, electronics, etc. require standard T1 (copper) and T2 (sensor/chip) advanced metals
        \end{itemize}
        \item Fuels: N/A (the refueling equipment itself does not require fuel to construct)
        \item Chemicals:
        \item Biomaterials: N/A
        \item Nuclear materials: N/A
    \end{itemize}
\end{itemize}
